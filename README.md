BABE_Herb4MO_CON — Canopy vs. understory herbivory on control trees across latitude

Analysis code for the BABE 4MO control-tree herbivory dataset: leaf herbivory measured on marked twigs of canopy and understory trees over a four-month (4MO) period at six forest sites spanning ~85° of latitude, from temperate Europe through the tropics to temperate Australia.

Author: Katerina Sam (2025–2026)

Study design
Level	Description
Site	6 forest sites along a latitudinal gradient (see table below)
Stratum	Canopy vs. Understory
Plant species	Several tree species per site (PlantSpeciesAnal, 44 species in total)
Individual	Individual trees per species, coded Site_SpeciesID_Individual_Year (e.g. BUB_SP1_1_CD)
Twig	3 marked twigs per individual (TwigCode)
Year / patrol	PatrolIndiv: AB = year 1, CD = year 2
Time	Herbivory measured at the Start and End of the 4-month period (Patrol2)
Sites
Code	Latitude	Climate zone
LAK	51.20	Temperate
TOM	42.68	Temperate
BUB	21.60	Tropical
KAK	−5.13	Tropical
DRO	−16.10	Tropical
EUC	−33.62	Temperate

Sites are ordered north → south throughout the analyses (LAK, TOM, BUB, KAK, DRO, EUC).

Response variables

Calculated per twig in 01_data_checking_surveying.R:

HerbProp_Start — proportion of leaf area damaged at the start of the experiment
HerbProp_End — proportion of leaf area damaged after four months (standing herbivory)
Diff (renamed TwigHerbPropDiff in script 03) — HerbProp_End − HerbProp_Start; negative and missing values are set to 0

Workflow

Run the scripts in numerical order with the project root as the working directory.

01_data_checking_surveying.R — data survey and preparation
Builds a site × species × patrol table of plant species and checks that patrols A/B and C/D used the same species (consistency check).
Exports collapsed species-by-stratum summary tables.
Averages leaf-level measurements per twig and reshapes Start/End values into separate columns.
Computes the Start→End change in herbivory per twig.

Outputs (data/output/):

summary_by_site_species_patrol.csv
summary_by_site_species_strata_collapsed.csv
twig_summary_start_end.csv
twig_summary_start_end_difference.csv ← main analysis file used by scripts 02–04 and 07
02_herbivory_START_…R — herbivory at the start of the season
03_herbivory_CHANGE_…R — change in herbivory over four months
04_herbivory_END_…R — standing herbivory at the end of the season

All three scripts share the same modelling approach:

Model: glmmTMB with beta family (logit link); response + 0.0001 to avoid exact zeros
Random effects: (1 | PlantSpeciesAnal) + (1 | IndividualCode) — twigs nested within individuals, individuals within species
Candidate fixed-effect structures:
Model	Fixed effects
null	1
latitude	poly(Lat, 2)
strata	Strata
add	Strata + poly(Lat, 2)
int	Strata * poly(Lat, 2)
climate	Climate
climateadd	Climate + Strata
climateInt	Climate * Strata
Model selection: AICc (bbmle::AICctab, MuMIn::model.sel)
Inference & figures: estimated marginal means with emmeans (response scale)
Scripts 02 and 03: continuous latitude model (Strata * poly(Lat, 2))
Script 04: climate-zone model (Climate * Strata), plotted per site

Figure_1b_HerbivoryDiff_Emmeans.pdf (03, emmeans-based)
Combined panel A/B via ggpubr::ggarrange (03; needs p1 from script 02 in the same session)
End-of-season standing herbivory by site and stratum (04; not yet saved to file)

Script 03 also writes data/output/prediction_herbivory.csv.

05_phylogeny_build_plot_20260120.R — plant phylogeny

Builds a phylogeny of the 44 tree species with V.PhyloMaker2 (GBOTB.extended.LCVP megatree, scenario S3), fills missing family assignments by hand, saves it as Newick and plots it with site symbols/colours at the tips.

06_Plotting_map_Figure1.R — study-site map

Plots tropical/subtropical (WWF major habitat types 1–3) and temperate (4–5) forest biomes from the TNC ecoregion shapefile with sf, cropped to the Old World / Australasia, and overlays the study sites.

07_checking_EUC.R — EUC site check

Supplementary check of canopy vs. understory end-of-season herbivory at EUC, for Eucalyptus tereticornis specifically (Wilcoxon and t-test) and for all EUC species.
